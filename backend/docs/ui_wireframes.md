# 1. Purpose

This document defines the initial wireframes and screen layouts for
Exam Arena.

These wireframes are intentionally low-fidelity.

Their purpose is to define user interaction,
screen hierarchy,
and navigation before visual design begins.

---

# 2. Design Philosophy

Exam Arena is not an online coaching website.

It is a competitive gaming platform for learning.

The UI should feel:

- Fast
- Minimal
- Competitive
- Rewarding
- Modern

Avoid:

- Long paragraphs
- Information overload
- Multiple menus
- Large tables
- Coaching-style interfaces

Every primary action should be reachable within two clicks.
